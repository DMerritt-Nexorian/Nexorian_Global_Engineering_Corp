## 1. SECURITY POSTURE & COMMITMENT
Nexorian Corporation prioritizes post-quantum security, memory safety, and secure software distribution. All release candidate artifacts undergo static analysis, dependency auditing, secret scanning, and automated build integrity verification.

## 2. REPORTING A VULNERABILITY
If you discover a potential security vulnerability in any Project Nexus software component or web portal, please report it immediately to our security response team:
- **Email:** `security@nexorian.com` (or authorized security contact)
- **Encryption:** PGP Key available upon request.

Please include:
- Description of the vulnerability and affected product/version.
- Steps to reproduce or proof-of-concept.
- Potential impact assessment.

## 3. RESPONSIBLE DISCLOSURE POLICY
- Please allow up to 48 hours for initial acknowledgment.
- Do not publicly disclose the vulnerability until Nexorian has had reasonable time to investigate, remediate, and issue a patch or advisory.
- Do not execute destructive actions, access customer data, or launch Denial-of-Service (DoS) attacks during research.
