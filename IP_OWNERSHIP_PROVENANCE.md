## AI Footprint Status Definitions

- `CLEAN`: No identified AI branding, agent identity, or AI metadata in release artifacts.
- `HISTORICAL AI ATTRIBUTION — CURRENT ARTIFACTS CLEAN`: Repository git history contains automated or agent commits, but customer-facing commercial artifacts are clean.
- `AI/BOT METADATA PRESENT`: AI or bot metadata present in active source/docs requiring clean-room cleanup.
- `AI PROVENANCE UNKNOWN`: Repository remote not directly inspectable in current sandbox execution session.
- `HUMAN REVIEW REQUIRED`: Third-party or multi-author contributions require IP assignment review.
